# Dino Survivor

원본을 유지한 별도 확장판입니다. 이 폴더의 `index.html`을 더블클릭하면 인터넷이나 서버 없이 실행됩니다. 오리지널은 상위 폴더의 `index.html`입니다.

## 조작과 성장

- Space / ↑ / 게임 화면 클릭으로 시작·점프합니다. 공격 능력은 획득 후 자동 발동합니다.
- 생존 1초마다 10점, 장애물 파괴마다 12점을 얻습니다. 첫 80점부터 레벨이 오르고 세 후보 중 하나를 클릭하거나 숫자 1·2·3으로 고릅니다. 선택 중에는 시간이 멈춥니다.
- 같은 능력을 다시 고르면 강화됩니다. 시간이 지날수록 선인장·바위 무리가 많아지고 익룡이 등장합니다. 익룡은 지상에 머물러 피할 수 있습니다.
- 게임 오버 후 0.4초가 지나면 같은 입력이나 재시작 버튼으로 다시 시작합니다. 점수와 능력은 모두 초기화됩니다.

## 능력 9종

| 능력 | 효과 / 강화 방향 |
| --- | --- |
| 입 빔 | 입 높이에서 전방 관통 빔 / 간격 감소·두께 증가 |
| 도약 강화 | 점프 높이와 체공 시간 증가 / 도약력 증가 |
| 운석 소환 | 장애물 위치에 운석 낙하·범위 파괴 / 범위 증가·간격 감소 |
| 보호막 | 충돌 흡수 후 잠깐 무적·자동 충전 / 저장량 증가·충전 단축 |
| 지면 충격파 | 전방 지상 장애물 범위 파괴 / 범위 증가·간격 감소 |
| 지원 드론 | 가까운 장애물을 향해 유도탄 발사 / 발사 간격 감소·탄 크기 증가 |
| 연쇄 번개 | 가까운 장애물부터 연쇄 파괴 / 대상 수 증가·간격 감소 |
| 냉기장 | 주변 장애물 이동 속도 감소 / 범위·감속 효과 증가 |
| 공중 도약 | 공중에서 추가 점프 / 가능한 추가 점프 횟수 증가 |
